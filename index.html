How It Works

Privacy-first architecture built for the MLH Midnight Hackathon AI Track

Scan

Submit a suspicious URL or email. Our Groq-powered Llama 3.1 model analyzes it with deterministic threat-hunting rules.

Scrub

The moment analysis completes, raw data is permanently discarded from server memory. Nothing sensitive is ever stored.

Hash & Log

A SHA-256 ZK-proof hash is generated and logged to SQLite + the Midnight Compact ledger — verifiable but totally blind.
